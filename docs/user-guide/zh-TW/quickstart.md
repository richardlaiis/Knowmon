# 快速開始

這一頁帶你從開啟 Knowmon 到寫出第一組互相連結的筆記，大約五分鐘。

> 本說明的快捷鍵以 Windows / Linux 為準，macOS 請把 `Ctrl` 換成 `Cmd`（`Ctrl+Tab` 除外）。

## 1. 選擇一個 vault

第一次開啟 Knowmon 時會看到歡迎畫面。按 **Open folder**，選一個資料夾：

- 可以是一個**空資料夾**，從零開始。
- 也可以是**已經有 Markdown 筆記的資料夾**（例如舊的 Obsidian vault）。Knowmon 會讀取裡面所有的 `.md` 檔並建立索引，不會修改你的檔案。

這個資料夾就是你的 **vault**。之後想換 vault，點左上角的 vault 名稱即可。

> **提示**：Knowmon 啟動時不會自動開啟上次的 vault，但選擇資料夾的對話框會從上次的位置開始，按一下就回來了。

## 2. 建立第一篇筆記

點左側欄上方的「新增筆記」圖示（或在檔案樹空白處按右鍵 → New note），在出現的輸入框打上名稱，例如 `讀書清單`，按 `Enter`。

筆記會開在新分頁，直接開始打字即可：

```markdown
# 讀書清單

- [ ] 原子習慣
- [ ] 深度工作
```

**不需要按儲存**——停止輸入約 0.5 秒後會自動存檔。想立刻存也可以按 `Ctrl+S`。

## 3. 用 `[[連結]]` 串起筆記

把清單改成這樣：

```markdown
- [ ] [[原子習慣]]
- [ ] [[深度工作]]
```

輸入 `[[` 時會跳出筆記名稱的補全選單。這兩篇筆記現在還不存在也沒關係，按住 `Ctrl` 點擊 `[[原子習慣]]`，Knowmon 會在 vault 根目錄幫你建立它並打開。

在「原子習慣」裡寫幾句心得，看看右側面板的 **Backlinks**：它會列出「讀書清單」以及連結所在的那一行。這就是反向連結——你不需要在兩邊都寫連結。

## 4. 寫一篇日記

建立一篇檔名以日期開頭的筆記，例如 `2026-10-20`：

```markdown
# 2026-10-20

今天讀完 [[原子習慣]] 第三章，想試試「習慣堆疊」。
```

檔名開頭的日期就是這篇筆記的**事件日期**。多寫幾天，按 `Ctrl+Shift+T` 打開**時間軸**，就能依日期瀏覽；同一個資料夾裡有日期的筆記也會在圖譜中自動以 **Sequence** 邊串成一條鏈。詳見 [時間脈絡](time.md)。

## 5. 找到你的筆記

| 想做的事                 | 方法                                            |
| ------------------------ | ----------------------------------------------- |
| 知道筆記名稱，直接跳過去 | `Ctrl+O` 打開 Quick switcher，打幾個字，`Enter` |
| 找內文中的某個詞         | `Ctrl+Shift+F` 搜尋                             |
| 看筆記之間的關係         | `Ctrl+G` 打開圖譜                               |
| 依時間回顧               | `Ctrl+Shift+T` 打開時間軸                       |

## 6. （可選）啟用本地 AI

安裝 [Ollama](https://ollama.com) 並下載兩個模型：

```bash
ollama pull bge-m3      # 用來理解筆記的意思（embedding）
ollama pull qwen3:8b    # 用來總結、回答、執行 Agent 任務
```

Ollama 在背景執行時，左側欄底部會從「Indexing …」變成 **AI ready**。接著試試：

- 開著一篇筆記按 `Ctrl+Shift+S`：總結這篇筆記。
- 按 `Ctrl+Shift+A`，問「我讀原子習慣時有什麼想法？」：從你的筆記中找答案，並附上來源。

詳見 [設定本地 AI](ai-setup.md)。
