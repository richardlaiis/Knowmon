# 總結與問答

> 需要 [本地 AI](ai-setup.md)。

右側面板的 **AI** 分頁有三種模式：**Chat**（問答）、**Agent**、**Summary**（總結）。這一頁介紹 Summary 與 Chat；Agent 見 [Agent](agent.md)。

## 總結（Summary）

把一篇長筆記濃縮成幾個重點。

### 使用方法

1. 開著要總結的筆記。
2. 按 `Ctrl+Shift+S`，或筆記右上角的 **Summarize**。
3. 右側面板會切到 AI → Summary，逐字顯示條列式的總結。

**只想總結一部分？** 先選取那段文字再按 `Ctrl+Shift+S`。標題會顯示「Selection in 筆記名稱」。

### 總結的內容

- 以條列方式呈現，支援粗體、清單、程式碼等格式。
- **保留原文中的 `[[連結]]`**，而且可以點擊（`Ctrl+點擊`開新分頁）。AI 不會憑空捏造原文沒有的連結。
- 很長的筆記（超過約 12000 字）會先分段摘要再合併，所以需要多一點時間。

### 按鈕

| 按鈕           | 作用                                  |
| -------------- | ------------------------------------- |
| **中文 / EN**  | 總結使用繁體中文或英文，選擇會被記住  |
| **Stop**       | 中途停止                              |
| **Regenerate** | 重新總結（例如切換語言後）            |
| **Copy**       | 複製總結的 Markdown，可以直接貼進筆記 |

> **提示**：筆記是英文、但你想要中文總結（或相反）時，切換「中文 / EN」即可，原文的連結會保持原樣。

## 問答（Chat）

向你的筆記提問。AI 會先搜尋相關的筆記，只根據找到的內容回答，並標註每句話的出處。

### 使用方法

按 `Ctrl+Shift+A` 打開 Chat 並聚焦輸入框，輸入問題後按 `Enter`（`Shift+Enter` 換行）。

```
深度工作的重點是什麼？
```

你會看到：

1. 「Searching notes…」：正在找相關的筆記。
2. 回答逐字出現，句子後面有 **[1]**、**[2]** 之類的引用編號。
3. 回答下方列出被引用的來源。

**點擊引用編號或來源**會開啟該筆記，並捲到被引用的那一段（`Ctrl+點擊`開新分頁）。沒被引用、但有被搜尋到的筆記收在「sources searched」裡，點開可以查看。

### 用時間縮小範圍

問題裡提到時間時，Knowmon 會自動偵測，只用那段期間的筆記回答。輸入時，輸入框上方就會即時顯示偵測到的範圍。

| 你可以這樣寫                                              | 範圍            |
| --------------------------------------------------------- | --------------- |
| 今天、昨天、前天                                          | 那一天          |
| 這週、上週、上上週                                        | 週一到週日      |
| 這個月、上個月                                            | 整個月          |
| 今年、去年                                                | 整年            |
| 最近 7 天、過去兩週、最近 3 個月                          | 到今天為止      |
| 9 月、九月份                                              | 最近一次的 9 月 |
| `2026-09`、2026 年 9 月                                   | 該月            |
| `2026-10-04`、2026 年 10 月 4 日                          | 那一天          |
| `2026-10-04 到 2026-10-06`                                | 日期範圍        |
| today, last week, this month, past 3 days, September 2026 | 對應的英文寫法  |

判斷依據是筆記的**事件時間**（`date` 屬性或日期檔名），沒有的話用最後修改日。

**範例**：

```
上個月我讀了哪些書？有什麼心得？
```

```
2026-10-04 到 2026-10-06 之間做了什麼？
```

只有時間、沒有主題的問題（「上週寫了什麼？」），會直接列出那段期間的筆記作為來源。

#### 手動調整範圍

| 操作                 | 作用                                                       |
| -------------------- | ---------------------------------------------------------- |
| 按偵測範圍旁的 **×** | 這次不依日期篩選（顯示為「No date filter」，再點一下恢復） |
| **Date range…**      | 手動選擇開始與結束日期                                     |

手動範圍只對下一個問題有效，送出後恢復成自動偵測。

### 追問

Chat 會記得最近幾輪對話，所以可以接著問：

```
深度工作的重點是什麼？
那第二點要怎麼實踐？
```

想換個話題時，按 **New chat** 清空對話，避免前面的內容干擾。

### 回答的語言

AI 會用你提問的語言回答：用中文問就用繁體中文回答，用英文問就用英文回答。

```
What are the key ideas of Atomic Habits?
```

### 誠實的「不知道」

如果你的筆記裡沒有相關內容，AI 會直接說筆記裡沒有，而不是自己編造答案。完全找不到任何相關筆記時，甚至不會呼叫模型。

### 把回答存成筆記

按回答下方的 **Copy**，貼到筆記裡。引用編號會自動換成 `[[來源標題]]` 連結，這樣你的筆記也會連回原本的來源。

### 其他

- **Stop**：中途停止回答。
- 對話只存在記憶體中，關閉 App 或換 vault 時清空。
- 使用中文輸入法選字時按的 `Enter` 不會送出問題。

## 什麼時候用哪一個？

| 想做的事                                   | 用                                        |
| ------------------------------------------ | ----------------------------------------- |
| 快速掌握一篇長筆記                         | Summary                                   |
| 從很多筆記中找答案、回顧某段時間           | Chat                                      |
| 不只問，還要 AI 幫你整理、建立筆記、加標籤 | [Agent](agent.md)                         |
| 只是想找到某篇筆記                         | [Hybrid 搜尋](search.md#hybrid用意思搜尋) |
