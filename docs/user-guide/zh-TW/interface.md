# 介面導覽

開啟 vault 後，Knowmon 的視窗分成三欄：

```
┌──────────────┬──────────────────────────────────┬──────────────────┐
│ 左側欄        │ 分頁列                            │ 右側面板          │
│              ├──────────────────────────────────┤                  │
│ vault 名稱    │                                  │ Backlinks        │
│ Files│Search │        編輯器 / 圖譜 / 時間軸      │ Local graph      │
│ Graph│Timeline│                                 │ AI               │
│ Go to…       │                                  │                  │
│              │                                  │                  │
│ 檔案樹        │                                  │                  │
│ 或 搜尋結果   │                                  │                  │
│              │                                  │                  │
│ AI 狀態       │                                  │                  │
└──────────────┴──────────────────────────────────┴──────────────────┘
```

三欄之間的分隔線可以拖曳調整寬度，**雙擊分隔線**恢復預設寬度。左右兩欄都可以收起來（`Ctrl+B`、`Ctrl+Alt+B`，或分頁列兩端的按鈕）。寬度與開關狀態會被記住。

## 左側欄

### 標題列

| 元素           | 作用                                           |
| -------------- | ---------------------------------------------- |
| vault 名稱     | 滑鼠停留顯示完整路徑；點擊可切換到另一個 vault |
| 新增筆記圖示   | 在 vault 根目錄新增筆記                        |
| 新增資料夾圖示 | 在 vault 根目錄新增資料夾                      |
| 月亮／太陽圖示 | 切換深色／淺色主題                             |

### 導覽按鈕

| 按鈕         | 作用                                                     |
| ------------ | -------------------------------------------------------- |
| **Files**    | 顯示檔案樹                                               |
| **Search**   | 顯示搜尋面板（`Ctrl+Shift+F`），見 [搜尋](search.md)     |
| **Graph**    | 打開圖譜分頁（`Ctrl+G`），見 [圖譜](graph.md)            |
| **Timeline** | 打開時間軸分頁（`Ctrl+Shift+T`），見 [時間脈絡](time.md) |
| **Go to…**   | 打開 Quick switcher（`Ctrl+O`）                          |

### 檔案樹

- 資料夾排在前面，只列出 `.md` 筆記。圖片等其他檔案不會出現在這裡（但存放它們的資料夾會）。
- 名稱以 `.` 開頭的檔案與資料夾（例如 `.git`、`.obsidian`、`.knowmon`）不會顯示。
- **右鍵**：New note、New folder（建在你按的那個資料夾裡）、Rename、Delete。
- **拖曳**：把筆記或資料夾拖到另一個資料夾上即可搬移；拖到空白處就移回根目錄。拖著停在收合的資料夾上約 0.6 秒，它會自動展開。

### AI 狀態

側欄最下方顯示本地 AI 的狀態，點擊可打開 AI 分頁：

| 顯示                    | 意思                                       |
| ----------------------- | ------------------------------------------ |
| AI: checking…           | 正在檢查 Ollama                            |
| AI offline              | 連不上 Ollama；其他功能不受影響            |
| Indexing 12/40          | 正在背景為筆記建立語意索引                 |
| AI ready                | 一切就緒                                   |
| AI: needs attention     | 有問題，例如模型尚未下載；滑鼠停留可看原因 |
| Agent: confirm a change | Agent 正在等你確認一個修改                 |

## 中間：分頁與主區域

主區域可以開多個分頁，分頁有三種：

- **筆記**：每篇筆記一個編輯器。同一篇筆記只會有一個分頁，再次開啟會直接切過去。
- **圖譜**：全 vault 的關係圖，最多一個。
- **時間軸**：依時間瀏覽筆記，最多一個。

### 開啟筆記的規則

在檔案樹、搜尋結果、反向連結、圖譜、時間軸中**點擊**一篇筆記，會**取代目前的分頁**；按住 `Ctrl` 點擊（或用滑鼠中鍵）則**開在新分頁**。新建立的筆記一律開在新分頁。

這個設計讓你在瀏覽時不會累積一大堆分頁，需要對照時再刻意開新分頁。

### 分頁列操作

| 操作                          | 作用                 |
| ----------------------------- | -------------------- |
| 拖曳分頁                      | 調整順序             |
| 中鍵點擊分頁 / `Ctrl+W`       | 關閉                 |
| 右鍵分頁                      | Close / Close others |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 下一個／上一個分頁   |
| 「+」按鈕 / `Ctrl+T`          | 在新分頁開啟一篇筆記 |

分頁會被記住：關掉 Knowmon 再開同一個 vault，上次的分頁都還在（每個 vault 各自記錄）。

### 筆記分頁的右上角

| 按鈕                      | 作用                                               |
| ------------------------- | -------------------------------------------------- |
| **Summarize**             | 用 AI 總結這篇筆記（或選取的文字），`Ctrl+Shift+S` |
| **Live preview / Source** | 切換即時渲染與原始碼模式，`Ctrl+E`                 |

## 右側面板

右側面板跟著**目前的筆記分頁**變化，有三個分頁：

| 分頁            | 內容                                                                                                              |
| --------------- | ----------------------------------------------------------------------------------------------------------------- |
| **Backlinks**   | 哪些筆記連到這一篇，以及連結所在的那一行。見 [連結](links.md)                                                     |
| **Local graph** | 以目前筆記為中心的小型圖譜。見 [圖譜](graph.md)                                                                   |
| **AI**          | Chat（問答）、Agent、Summary（總結），以及 AI 狀態與設定。見 [總結與問答](summary-and-chat.md)、[Agent](agent.md) |

目前的分頁是圖譜或時間軸時，Backlinks 與 Local graph 會顯示「No note is open in this tab.」。

## 主題

Knowmon 有兩個主題：米白色的淺色主題，以及偏深的深色主題（程式碼使用 Nord 配色）。用左上角的月亮／太陽圖示切換，選擇會被記住，圖譜的顏色也會跟著換。

## 選單列

選單列平常是隱藏的，按 `Alt` 顯示。
