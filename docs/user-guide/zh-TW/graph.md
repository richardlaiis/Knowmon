# 圖譜

圖譜把每篇筆記畫成一個點，筆記之間的關聯畫成線，讓你一眼看出哪些想法聚在一起、哪些筆記是樞紐、哪些還孤零零的。

Knowmon 有兩種圖譜：

- **全域圖**：整個 vault，開在主區域的分頁裡（`Ctrl+G`）。
- **局部圖**：只看目前筆記附近，在右側面板的 **Local graph** 分頁。

## 全域圖

按 `Ctrl+G` 或左側欄的 **Graph**。圖譜是一種分頁，最多只會有一個；切到別的分頁再切回來，它還保持原樣，不需要重新計算。

### 操作

| 操作             | 作用                     |
| ---------------- | ------------------------ |
| 滾輪             | 縮放                     |
| 拖曳背景         | 平移                     |
| 拖曳節點         | 移動該節點               |
| 滑鼠停在節點上   | 高亮這篇筆記與相連的筆記 |
| 點擊節點         | 在目前分頁開啟該筆記     |
| `Ctrl+點擊` 節點 | 在新分頁開啟             |

節點越大，代表連結越多。尚未建立的筆記（只出現在 `[[連結]]` 中）不會顯示。

### 工具列

| 項目                  | 作用                                                  |
| --------------------- | ----------------------------------------------------- |
| `12 notes · 18 edges` | 目前顯示的筆記與線數；有篩選時顯示「8 of 12 notes」   |
| 邊類型按鈕            | 開關各種線，見下方                                    |
| **Labels**            | 顯示或隱藏筆記名稱（縮得很小時名稱會自動隱藏）        |
| **Fit**               | 縮放到剛好看見全部                                    |
| **Re-layout**         | 丟掉目前的位置，重新排版                              |
| **Settings**          | 時間與 Semantic 邊的參數，見 [時間脈絡](time.md#設定) |

工具列下方是**時間範圍滑桿**，見下方「依時間篩選」。

### 排版

排版在背景計算，筆記多時工具列會顯示「Laying out… 40%」，完成前也可以操作。節點的位置會被記住（直到關閉 App），新增筆記時只把新節點放在鄰居旁邊，不會整張重排。筆記名稱經過特別處理，在任何縮放倍率下都不會互相重疊。

覺得版面亂了，按 **Re-layout**。

## 線的種類

工具列上每個邊類型按鈕都附有該類型的線條樣式，點擊即可開關，選擇會被記住。

| 按鈕         | 類型           | 什麼時候會有這條線                          |
| ------------ | -------------- | ------------------------------------------- |
| **Links**    | Wikilink       | 一篇筆記裡寫了 `[[另一篇]]`；寫越多次線越粗 |
| **Session**  | 同一段工作時間 | 兩篇筆記在同一個工作 session 中被編輯過     |
| **Same day** | 同一天         | 兩篇筆記的事件日期相同（或在設定的天數內）  |
| **Sequence** | 前後篇         | 同一個資料夾中，依事件日期排序相鄰的兩篇    |
| **Semantic** | 內容相似       | 兩篇筆記的內容意思相近（需要本地 AI）       |

Session、Same day、Sequence 的詳細規則見 [時間脈絡](time.md)。

**關掉某種線時，它也不參與排版**，所以版面會稍微調整，但會沿用原本的位置，不會整張重排。

> **試試看**：只開 Links，看你手動建立的知識結構；只開 Session，看你平常哪些主題會一起思考；只開 Semantic，找出內容相關卻還沒連起來的筆記——這些常常值得補上一個 `[[連結]]`。

### Semantic 邊

> 需要 [本地 AI](ai-setup.md)，並等背景索引完成（左側欄顯示 AI ready）。

Knowmon 用 embedding 模型比較每兩篇筆記的內容，每篇筆記最多連到最相似的 5 篇，而且相似度要達到門檻（預設 0.65）。兩個數字都可以在 **Settings** 裡調整：

| 設定                 | 預設 | 範圍     | 說明                         |
| -------------------- | ---- | -------- | ---------------------------- |
| Similarity threshold | 0.65 | 0.3–0.95 | 越高線越少、越嚴格           |
| Max per note         | 5    | 1–20     | 每篇最多連到幾篇最相似的筆記 |

## 依時間篩選

工具列下方的時間列可以暫時隱藏某段時間以外的筆記。它**只隱藏節點，不改變排版**：筆記在原本的位置出現或消失，所以拖動滑桿時你可以看到網絡如何隨時間長出來。

| 項目                                       | 作用                                           |
| ------------------------------------------ | ---------------------------------------------- |
| 時間軸選單（**Event date** / **Written**） | 用哪一種時間判斷：筆記講的日期，或你寫它的日期 |
| 滑桿                                       | 拖動兩端選擇範圍                               |
| **Undated**                                | 勾選時，沒有日期的筆記一直顯示；取消時隱藏     |
| **Reset**                                  | 恢復全部範圍並顯示沒有日期的筆記               |

兩種時間的差別見 [時間脈絡](time.md#兩種時間)。

**範例**：選 Written、把滑桿拉到上週，取消 Undated——圖譜只剩上週有動過的筆記，看看那週你的注意力都放在哪裡。

> 滑桿拉滿且 Undated 勾選時（預設），兩種時間軸看起來會一模一樣，這是正常的。

## 局部圖

右側面板切到 **Local graph**。它以目前的筆記為中心（以強調色標示），只畫出附近的筆記，換筆記時跟著更新。

| 項目             | 作用                                            |
| ---------------- | ----------------------------------------------- |
| **Depth**（1–3） | 往外找幾層：1 = 直接相連，2 = 再加上鄰居的鄰居… |
| **Fit**          | 縮放到剛好看見全部                              |
| 邊類型按鈕       | 和全域圖一樣，但是獨立設定                      |

局部圖**先篩選線的種類，再找鄰居**。例如只開 Sequence，局部圖就只沿著前後篇延伸，正好是一條日記鏈。

## 已知限制

- Sequence 有方向（早 → 晚），但圖上沒有畫出箭頭。
- 同一對筆記同時有多種線時，線會重疊，只看得到最上面那條。
