# 常見問題

## 一般

### Knowmon 會修改我原有的筆記嗎？

不會主動修改。開啟 vault 時 Knowmon 只讀取檔案並建立索引。只有以下情況會寫入筆記：你自己編輯、點擊核取方塊、在 Agent 的確認卡片按 **Apply**。

### 為什麼打開 Knowmon 時沒有自動開啟上次的 vault？

這是刻意的設計。按 **Open folder** 時，對話框會從上次的 vault 位置開始，點一下就能回去。

### 我可以同時開多個 vault 嗎？

一次一個。點左上角的 vault 名稱可以切換，每個 vault 會各自記住開著的分頁。

### 支援哪些作業系統？

Linux、macOS、Windows。macOS 上快捷鍵的 `Ctrl` 改為 `Cmd`。

## 編輯

### 我改了筆記名稱，其他筆記的連結斷了

Knowmon 改名時不會自動更新其他筆記裡的 `[[舊名稱]]`。可以用 `Ctrl+Shift+F` 搜尋舊名稱，逐一修改。

### 我沒有按儲存，內容會不會不見？

不會。停止輸入 0.5 秒後就會自動儲存，切換分頁、關閉分頁、換 vault 之前也會先存檔。

### 為什麼點連結沒有反應？

連結需要 **`Ctrl+點擊`** 才會開啟，單純點擊只會把游標移過去，方便你編輯連結文字。

### 為什麼 `Ctrl+G` 不是「找下一個」？

`Ctrl+G` 在 Knowmon 中用來開圖譜。尋找時請用 `F3` / `Shift+F3`。

### 圖片沒有顯示

確認：

- 使用 `![說明](路徑)` 語法，而不是 `![[檔名]]`。
- 路徑是**相對於這篇筆記**的位置。例如筆記在 `日記/` 裡，圖片在根目錄的 `attachments/`，要寫 `../attachments/圖.png`。
- 不是網址，也不是絕對路徑。
- 目前不是原始碼模式（`Ctrl+E`）。

顯示紅色「Image not found」代表語法正確但找不到檔案。

### 表格沒有渲染

目前編輯器不渲染表格，會以原始 Markdown 顯示（AI 總結中的表格也是）。

## 搜尋

### 搜尋某個詞找不到，但我確定有寫

- Keyword 模式要求**所有詞都出現**，試著減少詞數。
- 該詞是否寫在 frontmatter 裡？屬性區塊不會被搜尋。
- 試試 Hybrid 模式，用意思來找。

### Hybrid 搜尋顯示「Semantic search is unavailable」

Ollama 沒有執行、Embedding 模型沒下載，或索引還沒建好。看左側欄底部的 AI 狀態，見 [設定本地 AI](ai-setup.md#狀態與疑難排解)。

## 圖譜與時間

### 圖譜上沒有 Session 邊

Session 邊需要你在 Knowmon 裡（或 Knowmon 開著時）實際**編輯**過筆記。剛開啟的 vault 只有每篇一筆「建立」紀錄，這不算。試著在 30 分鐘內編輯兩篇筆記，再看圖譜。

另外，一個 session 編輯超過 20 篇筆記時，會被當成批次操作而不產生 Session 邊，可以在 Settings 調整。

### 時間軸的 Event date 模式是空的

你的筆記還沒有事件日期。在 frontmatter 加上 `date: 2026-10-20`，或讓檔名以 `2026-10-20` 開頭。見 [屬性](properties.md#date事件日期)。

### 圖譜的時間滑桿切換 Event date / Written 看起來沒差別

滑桿拉滿且勾選 Undated 時（預設），兩者會顯示所有筆記，看起來完全一樣。把滑桿縮小、或取消 Undated，就能看出差別。

### 圖譜版面很亂

按工具列的 **Re-layout** 重新排版。也可以關掉一些邊類型，只看你關心的關聯。

## AI

### 一直顯示「AI offline」

1. 確認 Ollama 正在執行：在終端機執行 `ollama list`，有回應就表示正常。
2. 在 AI 分頁的 **Settings** 確認位址（預設 `http://127.0.0.1:11434`）。
3. 按 **Retry**。

### 顯示「AI: needs attention」

通常是模型還沒下載。打開 AI 分頁看詳細原因，例如執行 `ollama pull bge-m3`。

### AI 很慢

只用 CPU 時，總結約 15–30 秒、Agent 任務約 1–4 分鐘，這是正常的。可以：

- 使用有 GPU 的電腦，或在 AI 設定中把 Ollama 位址指向區網中有 GPU 的電腦。
- 換成較小的 Chat 模型（品質會下降）。
- Agent 任務縮小範圍，例如指定日期或筆記名稱。

### Agent 顯示「does not support tool calling」

目前的 Chat 模型不支援工具呼叫。在 AI 設定中換成支援的模型，例如 `qwen3:8b`。

### AI 回答的內容不對

- 檢查回答下方的來源，看 AI 是根據哪些筆記回答的。
- 問題中的時間片語會被當成篩選條件，確認輸入框上方顯示的範圍是你要的。
- 問題太籠統時，換個說法、加入筆記中可能出現的關鍵字。
- 對話之前的內容可能有干擾，按 **New chat** 重新開始。

### 我的筆記會被傳到網路上嗎？

不會。所有 AI 運算都在你指定的 Ollama 伺服器上（預設是你自己的電腦）。

## 資料

### 我可以刪除 `.knowmon` 資料夾嗎？

`index.db` 可以刪，會自動重建。但 **`events.jsonl` 請不要刪**，它記錄了你的寫作歷程，刪除後無法找回，時間相關的功能會失去過去的資料。見 [檔案與資料](files-and-data.md)。

### 刪除筆記時出現「Failed to move item to trash」

vault 所在的位置不支援系統垃圾桶（例如 `/tmp`）。請把 vault 放在家目錄底下。
