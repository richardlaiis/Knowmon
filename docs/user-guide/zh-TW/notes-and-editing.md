# 筆記與編輯

## 筆記就是檔案

vault 裡每個 `.md` 檔就是一篇筆記，**檔名就是筆記的標題**。例如 `讀書筆記/原子習慣.md` 的標題是「原子習慣」。

這代表你可以：

- 用任何其他編輯器修改筆記，Knowmon 會自動偵測並更新。
- 用檔案總管或終端機新增、搬移、刪除筆記，檔案樹會跟著更新。
- 用 git、雲端硬碟等任何方式備份或同步整個資料夾。

## 管理筆記與資料夾

### 新增

- 左側欄上方的「新增筆記」「新增資料夾」圖示：建在 vault 根目錄。
- 在檔案樹的資料夾上按右鍵 → **New note** / **New folder**：建在該資料夾裡。

檔案樹會出現名稱輸入框，打好名稱按 `Enter`（或點別的地方）才會真正建立；按 `Esc` 或留空則取消。同一個資料夾裡不能有同名（不分大小寫）的筆記。

> 也可以直接寫一個不存在的 `[[連結]]`，再 `Ctrl+點擊` 它來建立筆記，見 [連結](links.md)。

### 重新命名

在檔案樹按右鍵 → **Rename**，`Enter` 確認、`Esc` 取消。改名時開著的筆記不會被關掉，游標位置與復原歷程都保留，編輯歷程也會跟著新名稱走。

> **注意**：改名**不會**自動改寫其他筆記裡的 `[[舊名稱]]`。改名後，原本連到它的連結會變成「尚未建立的筆記」。

### 搬移

把筆記或資料夾拖到另一個資料夾上。拖到檔案樹的空白處會移到根目錄。

### 刪除

右鍵 → **Delete**，確認後檔案會移到**系統垃圾桶**，需要時可以從垃圾桶還原。

## 自動儲存

停止輸入約 0.5 秒後自動存檔，`Ctrl+S` 立即存檔。切換或關閉分頁、改名、刪除、換 vault 之前也都會先存檔，所以不用擔心遺失內容。

### 筆記被外部修改時

如果你在別的編輯器改了一篇開著的筆記：

- 你在 Knowmon 裡**沒有**未存的內容 → 直接換成新版本。
- 你**剛好也在打字** → 分頁上方出現提示列，讓你選擇 **Load external version**（載入外部版本）或 **Keep my version**（保留你的版本）。

## 即時渲染（Live preview）

Knowmon 的編輯器預設是**即時渲染**模式：Markdown 符號會被隱藏，直接顯示排版後的樣子；當游標移到某個元素上時，才顯示它的原始語法讓你編輯。

- **行內元素**（粗體、斜體、刪除線、行內程式碼、連結、wikilink）：游標碰到該元素時顯示原始語法。
- **區塊標記**（標題的 `#`、引用的 `>`、清單符號、分隔線）：游標所在的那一行顯示原始語法。

按 `Ctrl+E` 或右上角的 **Live preview / Source** 按鈕切換到**原始碼模式**，看到完整的 Markdown。這個偏好會被記住。

### 支援的 Markdown 語法

| 語法        | 寫法                          | 說明                         |
| ----------- | ----------------------------- | ---------------------------- |
| 標題        | `# 標題`、`## 次標題` …       | 共六級                       |
| 粗體／斜體  | `**粗體**`、`*斜體*`          |                              |
| 刪除線      | `~~刪除~~`                    |                              |
| 行內程式碼  | `` `code` ``                  |                              |
| 連結        | `[文字](https://example.com)` | `Ctrl+點擊` 以系統瀏覽器開啟 |
| Wikilink    | `[[筆記名稱]]`                | 見 [連結](links.md)          |
| 清單        | `- 項目`、`1. 項目`           |                              |
| 待辦        | `- [ ] 待辦`、`- [x] 完成`    | 點擊核取方塊即可切換         |
| 引用        | `> 引用`                      |                              |
| 分隔線      | `---`                         |                              |
| 程式碼區塊  | ` ```python ` … ` ``` `       | 依語言上色                   |
| 圖片        | `![說明](attachments/圖.png)` | 見下方「圖片」               |
| Frontmatter | 文件開頭的 `---` 區塊         | 見 [屬性](properties.md)     |

表格與 HTML 會以原文顯示，不會渲染。

### 程式碼區塊

游標不在程式碼區塊內時，前後的 ` ``` ` 會隱藏，語言名稱顯示在右上角。程式碼依語言上色，支援大部分常見語言（第一次出現某種語言時才會載入）；不認得的語言以純文字顯示。

````markdown
```python
def greet(name):
    return f"Hello, {name}"
```
````

### 外部連結

為了避免打字時誤觸，外部連結需要 **`Ctrl+點擊`** 才會開啟，並交給系統瀏覽器。只允許 `http`、`https` 與 `mailto` 開頭的網址。

## 圖片

### 加入圖片

- **貼上**：截圖後在筆記裡按 `Ctrl+V`。
- **拖進來**：從檔案總管把圖片拖進編輯器。

圖片會存到 vault 根目錄的 `attachments/` 資料夾，並在游標處插入圖片語法：

```markdown
![](<attachments/Pasted image 20261020143015.png>)
```

- 路徑相對於目前的筆記；檔名有空白或括號時會用 `< >` 包起來。
- 剪貼簿的截圖會被命名為 `Pasted image 年月日時分秒.png`；拖進來的檔案保留原檔名。
- 名稱重複時自動加上編號，**絕不覆蓋**現有檔案。
- 單一檔案上限 50 MB。
- 剪貼簿同時有文字時，會照一般文字貼上。

### 圖片語法規則

Knowmon 只支援標準 Markdown 語法 `![說明](路徑)`，而且路徑必須**相對於這篇筆記所在的資料夾**：

| 寫法                                           | 會顯示嗎？                   |
| ---------------------------------------------- | ---------------------------- |
| `![](attachments/a.png)`（筆記在根目錄）       | ✓                            |
| `![](../attachments/a.png)`（筆記在子資料夾）  | ✓                            |
| `![](<my image.png>)` 或 `![](my%20image.png)` | ✓ 檔名有空白時兩種都可以     |
| `![](https://example.com/a.png)`               | ✗ 不顯示網路圖片             |
| `![](/home/me/a.png)`                          | ✗ 不支援絕對路徑             |
| `![[a.png]]`                                   | ✗ 不支援 Obsidian 的嵌入語法 |

找不到檔案時會顯示紅色的「Image not found」。

> **提示**：自己搬移了 `attachments` 裡的圖片後，記得修改筆記中的路徑。

游標不在圖片那一行時，整段語法會換成圖片；游標移上去時，原始語法與圖片會同時出現。原始碼模式不顯示圖片。

## 編輯技巧

除了一般的打字，編輯器還有這些常用操作（完整列表見 [快捷鍵](shortcuts.md)）：

| 快捷鍵                          | 作用                                                 |
| ------------------------------- | ---------------------------------------------------- |
| `Ctrl+F`                        | 在筆記內尋找與取代，`F3` / `Shift+F3` 下一個／上一個 |
| `Ctrl+D`                        | 同時選取下一個相同的文字（多重游標）                 |
| `Alt+↑` / `Alt+↓`               | 把整行往上／往下移                                   |
| `Shift+Alt+↑` / `Shift+Alt+↓`   | 複製整行                                             |
| `Ctrl+Shift+K`                  | 刪除整行                                             |
| `Ctrl+Shift+[` / `Ctrl+Shift+]` | 摺疊／展開標題、清單或程式碼區塊                     |

> 在其他編輯器中 `Ctrl+G` 常是「找下一個」，在 Knowmon 裡它用來開圖譜，請改用 `F3`。
