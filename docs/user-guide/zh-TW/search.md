# 搜尋與快速切換

Knowmon 有兩種找筆記的方式：

- **Quick switcher**（`Ctrl+O`）：**知道筆記名稱**時，用它最快。
- **搜尋**（`Ctrl+Shift+F`）：要找**內文**裡的字詞，或用意思來找。

## Quick switcher

按 `Ctrl+O`（或左側欄的 **Go to…**），輸入筆記名稱的一部分：

- 採用模糊比對，不必打完整名稱，也不必連續。例如打 `深工` 就能找到「深度工作」。
- 什麼都沒輸入時，**最近開過的筆記**排在最前面，方便來回切換。
- 每筆結果旁邊會顯示所在的資料夾。

| 按鍵                            | 作用           |
| ------------------------------- | -------------- |
| `↑` `↓`（或 `Ctrl+N` `Ctrl+P`） | 選擇           |
| `Enter`                         | 在目前分頁開啟 |
| `Ctrl+Enter`                    | 在新分頁開啟   |
| `Esc`                           | 關閉           |

按 `Ctrl+T`（或分頁列的「+」）會以「新分頁」模式打開 Quick switcher，此時 `Enter` 就會開在新分頁。

## 搜尋面板

按 `Ctrl+Shift+F`（或左側欄的 **Search**）。左側欄是關著的話會自動打開。搜尋框下方可以切換兩種模式：

### Keyword：關鍵字搜尋

邊打字邊顯示結果，適合找確定出現過的字詞。

- **多個詞用空白分開，必須全部出現**：`習慣 提示` 會找同時有「習慣」和「提示」的筆記。
- **中文不用斷詞**：2 個字的詞（例如 `習慣`）也找得到，中英混合（`中英混合 search`）也可以。
- **標題命中的排在前面**，其次依相關程度排序。
- 每筆結果顯示資料夾與一段摘要，摘要中命中的字會被標示出來。
- 只搜尋標題與內文，**不包含** frontmatter 屬性。

| 按鍵                   | 作用                          |
| ---------------------- | ----------------------------- |
| `Enter`                | 開啟第一個結果                |
| `Esc`                  | 清空搜尋框                    |
| 點擊結果 / `Ctrl+點擊` | 在目前分頁開啟 / 在新分頁開啟 |

### Hybrid：用意思搜尋

> 需要 [本地 AI](ai-setup.md)。

有時候你記得「大概在講什麼」，卻想不起當時用的字詞。Hybrid 模式結合三種方法：

1. **全文比對**：和 Keyword 一樣找字詞。
2. **語意比對**：用本地的 embedding 模型理解意思，找到內容相近的段落，即使用字完全不同。
3. **圖譜鄰居**：最相關的幾篇所連結的筆記也會加分。

輸入問題或描述後**按 `Enter`** 才會開始查詢（因為比較花時間），結果出來後再按一次 `Enter` 開啟第一筆。

每筆結果的標籤說明它為什麼被找到：

| 標籤        | 意思                       |
| ----------- | -------------------------- |
| **meaning** | 內容的意思相近（向量比對） |
| **text**    | 字詞相符（全文比對）       |
| **linked**  | 是其他高分筆記的連結鄰居   |

點擊結果會開啟筆記，並**捲到最相關的那一段**。

**範例**：在 test-vault 輸入 `培養好習慣的方法`。即使沒有任何筆記寫了這幾個字，「原子習慣」仍會出現在前面，標示 meaning。

#### 日期範圍

Hybrid 模式下，搜尋框旁邊有兩個日期欄位，可以只找某段期間的筆記。判斷的依據是筆記的**事件日期**（[`date` 屬性](properties.md)或日期檔名）；沒有事件日期的筆記則看最後修改日。

設定日期後按 `Enter` 查詢。

#### AI 離線時

Ollama 沒有執行、或語意索引還沒建好時，Hybrid 會退回關鍵字結果，並顯示「Semantic search is unavailable right now; showing keyword matches.」。

## 該用哪一個？

| 情境                           | 建議                                                 |
| ------------------------------ | ---------------------------------------------------- |
| 「我有一篇叫『週會』的筆記」   | `Ctrl+O`                                             |
| 「我記得寫過 `bm25` 這個詞」   | 搜尋 → Keyword                                       |
| 「我好像寫過關於專注力的東西」 | 搜尋 → Hybrid                                        |
| 「上個月我讀書時有什麼想法？」 | AI 分頁的 Chat，見 [總結與問答](summary-and-chat.md) |
