# 快捷鍵

macOS 上請把 `Ctrl` 換成 `Cmd`（`Ctrl+Tab` 除外）。

## 全域

在任何地方都有效（包括編輯器裡），而且優先於編輯器本身的同名快捷鍵。

### 導覽

| 快捷鍵         | 作用                                       |
| -------------- | ------------------------------------------ |
| `Ctrl+O`       | Quick switcher：以名稱找筆記，開在目前分頁 |
| `Ctrl+T`       | Quick switcher，開在新分頁                 |
| `Ctrl+Shift+F` | 搜尋（左側欄關著時會打開）                 |
| `Ctrl+G`       | 圖譜分頁                                   |
| `Ctrl+Shift+T` | 時間軸分頁                                 |

### 分頁與面板

| 快捷鍵                        | 作用                     |
| ----------------------------- | ------------------------ |
| `Ctrl+W`                      | 關閉目前分頁             |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 下一個／上一個分頁       |
| `Ctrl+B`                      | 開關左側欄               |
| `Ctrl+Alt+B`                  | 開關右側面板             |
| `Ctrl+E`                      | 切換即時渲染／原始碼模式 |

### AI

| 快捷鍵         | 作用                                         |
| -------------- | -------------------------------------------- |
| `Ctrl+Shift+S` | 總結目前的筆記；有選取文字時只總結選取的部分 |
| `Ctrl+Shift+A` | 打開 Chat（問答）並聚焦輸入框                |
| `Ctrl+Shift+G` | 打開 Agent 並聚焦輸入框                      |

## 編輯器

### Knowmon 專屬

| 快捷鍵                       | 作用                                                 |
| ---------------------------- | ---------------------------------------------------- |
| `Ctrl+S`                     | 立即儲存（平常停止輸入 0.5 秒後自動儲存）            |
| 輸入 `[[`                    | 筆記名稱補全：`↑` `↓` 選擇、`Enter` 插入、`Esc` 關閉 |
| `Ctrl+Space`                 | 手動叫出補全                                         |
| `Ctrl+點擊` `[[連結]]`       | 在目前分頁開啟；筆記不存在時在 vault 根目錄建立      |
| `Ctrl+Shift+點擊` `[[連結]]` | 在新分頁開啟                                         |
| `Ctrl+點擊` 外部連結         | 以系統瀏覽器開啟（只限 http、https、mailto）         |
| 點擊核取方塊                 | 切換 `- [ ]` ／ `- [x]`（即時渲染模式）              |
| `Ctrl+V` 圖片                | 貼上圖片，存到 `attachments/`                        |

### 文字編輯

| 快捷鍵                          | 作用                                           |
| ------------------------------- | ---------------------------------------------- |
| `Ctrl+Z`                        | 復原                                           |
| `Ctrl+Y` 或 `Ctrl+Shift+Z`      | 重做（macOS：`Cmd+Shift+Z`）                   |
| `Ctrl+F`                        | 在筆記內尋找與取代                             |
| `F3` / `Shift+F3`               | 找下一個／上一個                               |
| `Ctrl+D`                        | 多選下一個相同的文字                           |
| `Alt+↑` / `Alt+↓`               | 上下移動整行                                   |
| `Shift+Alt+↑` / `Shift+Alt+↓`   | 往上／往下複製整行                             |
| `Ctrl+Shift+K`                  | 刪除整行                                       |
| `Ctrl+]` / `Ctrl+[`             | 增加／減少縮排                                 |
| `Ctrl+Shift+[` / `Ctrl+Shift+]` | 摺疊／展開（macOS：`Cmd+Alt+[` / `Cmd+Alt+]`） |
| `Ctrl+/`                        | 切換註解（`<!-- -->`）                         |

> `Ctrl+G` 在 Knowmon 中用來開圖譜，所以「找下一個」請用 `F3`。

## Quick switcher 與搜尋框

| 快捷鍵                          | 作用                                                              |
| ------------------------------- | ----------------------------------------------------------------- |
| `↑` `↓`（或 `Ctrl+N` `Ctrl+P`） | 在 Quick switcher 中選擇                                          |
| `Enter`                         | 開啟（搜尋框：開啟第一個結果；Hybrid 模式下先查詢，再按一次開啟） |
| `Ctrl+Enter`                    | 開在新分頁                                                        |
| `Esc`                           | 關閉 Quick switcher／清空搜尋框                                   |

## Chat 與 Agent 輸入框

| 快捷鍵        | 作用 |
| ------------- | ---- |
| `Enter`       | 送出 |
| `Shift+Enter` | 換行 |

使用輸入法選字時按的 `Enter` 不會送出。

## 滑鼠

| 操作                                                 | 作用                                       |
| ---------------------------------------------------- | ------------------------------------------ |
| 點擊筆記（檔案樹、搜尋結果、反向連結、圖譜、時間軸） | 在目前分頁開啟                             |
| `Ctrl+點擊` 或中鍵                                   | 在新分頁開啟（圖譜節點只支援 `Ctrl+點擊`） |
| 右鍵檔案樹                                           | New note、New folder、Rename、Delete       |
| 拖曳檔案樹中的筆記或資料夾                           | 搬移到其他資料夾                           |
| 中鍵分頁                                             | 關閉分頁                                   |
| 拖曳分頁                                             | 調整順序                                   |
| 右鍵分頁                                             | Close / Close others                       |
| 拖曳面板之間的分隔線                                 | 調整寬度；雙擊恢復預設                     |
| 圖譜：滾輪／拖曳背景／拖曳節點                       | 縮放／平移／移動節點                       |

## 應用程式

| 快捷鍵   | 作用                   |
| -------- | ---------------------- |
| `Alt`    | 顯示選單列（平常隱藏） |
| `Ctrl+Q` | 結束                   |
| `F11`    | 全螢幕                 |
| `Ctrl+M` | 最小化                 |
