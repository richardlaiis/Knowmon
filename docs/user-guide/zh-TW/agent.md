# Agent

> 需要 [本地 AI](ai-setup.md)，且 Chat 模型必須支援工具呼叫（預設的 `qwen3:8b` 支援）。

[Chat](summary-and-chat.md#問答chat) 只能回答問題；**Agent** 則可以自己決定要搜尋什麼、讀哪幾篇筆記、查看哪些關聯，一步步完成較複雜的任務，必要時還能**建立筆記**或**加上標籤**。

所有會修改 vault 的動作，都會**先停下來等你確認**。

## 開始一個任務

按 `Ctrl+Shift+G`（或在 AI 分頁切到 **Agent**），輸入任務，按 `Enter` 或 **Run**。

第一次使用時，面板會顯示幾個範例，點一下就會填入輸入框：

- 上週寫了哪些筆記？各自連到哪些筆記？
- 把關於習慣的筆記整理成一篇摘要筆記
- 幫這個月的日記加上「回顧」標籤

## Agent 能做什麼

Agent 有六種「工具」，它會依任務自己選用：

| 工具               | 作用                                               | 步驟顯示                                     |
| ------------------ | -------------------------------------------------- | -------------------------------------------- |
| 搜尋筆記           | 以關鍵字與意思搜尋，可限定時間                     | Search "習慣" → 5 notes                      |
| 讀取筆記           | 讀一篇筆記的內容，長筆記分段讀                     | Read 原子習慣                                |
| 查看關聯           | 列出一篇筆記的連結、反向連結、時間邊與 Semantic 邊 | Connections of 深度工作 → 4 notes            |
| 列出某段期間的筆記 | 例如「上週」「2026-10」                            | Notes from 2026-10-04 – 2026-10-06 → 3 notes |
| 建立筆記 ✎         | 建立新筆記（**需要確認**）                         | Create 整理/比較.md                          |
| 加標籤 ✎           | 在 frontmatter 的 `tags` 加入標籤（**需要確認**）  | Add #回顧 to 2026-10-04                      |

> Agent **不會**修改或刪除既有筆記的內文，也不會改名或搬移檔案。建立筆記時絕不覆蓋已存在的檔案。

## 看懂任務的進行

任務進行時，面板會依序列出每一個步驟：

| 圖示 | 意思                                       |
| ---- | ------------------------------------------ |
| 轉圈 | 執行中                                     |
| ✓    | 完成                                       |
| !    | 發生錯誤（Agent 會看到錯誤並嘗試其他方法） |
| ?    | 等你確認                                   |
| ✕    | 你拒絕了這個修改                           |

**點開步驟**可以看到 Agent 傳給工具的參數與找到的筆記；點筆記開啟，`Ctrl+點擊`開新分頁。

步驟之間的文字以淡色顯示（Agent 的思考過程），最後一個步驟之後的文字才是**最終回答**。最終回答中的 `[[連結]]` 可以點擊。

## 確認修改

當 Agent 想建立筆記或加標籤時，會出現一張**確認卡片**，同時 Agent 按鈕、AI 分頁與左側欄底部都會提醒你（「Agent: confirm a change」）。

### 建立筆記

卡片上有可以修改的**路徑**與**內容**。如果內容中有指向不存在筆記的連結，卡片會列出來（「Links to notes that don't exist yet: …」），方便你決定要不要修正。

### 加標籤

卡片顯示要加的標籤（每個都可以按 × 拿掉），以及 frontmatter 修改前後的對照。

### 你的選擇

| 按鈕       | 結果                                           |
| ---------- | ---------------------------------------------- |
| **Apply**  | 依卡片上的內容（包含你修改過的部分）寫入 vault |
| **Reject** | 不寫入；Agent 會知道你拒絕了，並在回答中說明   |
| **Stop**   | 停止整個任務；等待中的修改不會寫入             |

> 等待確認的期間，你可以照常編輯筆記。加標籤時 Knowmon 會在套用的那一刻重新讀取檔案，不會蓋掉你剛剛的修改。如果那篇筆記正開著，套用後會自動重新載入。

## 範例

### 回顧一段期間

```
2026-10-04 到 2026-10-06 之間寫了哪些筆記？它們各自連到哪些筆記？
```

Agent 會先列出那三天的筆記，再逐篇查看關聯，最後整理成一段回答（以下為示意）：

```
✓ Notes from 2026-10-04 – 2026-10-06 → 3 notes
✓ Connections of 2026-10-04 → 2 notes
✓ Connections of 2026-10-05 → 4 notes
✓ Connections of 2026-10-06 → 3 notes

這三天的日記主要圍繞兩個主題：……
```

### 整理成一篇新筆記

```
把「原子習慣」和「深度工作」整理成一篇比較筆記，存在「整理」資料夾
```

Agent 會讀完兩篇筆記，然後提出一篇新筆記讓你確認。你可以先改標題或內容，再按 **Apply**。新筆記會立刻出現在檔案樹中。

### 批次加標籤

```
幫上週的日記加上「回顧」標籤
```

每一篇都會各自出現一張確認卡片。已經有這個標籤的筆記會被略過，不會要你確認。

## 寫出好任務的訣竅

- **說清楚範圍**：「上週的日記」比「最近的筆記」好。時間用說的就好（「上週」「這個月」「2026-09」），Knowmon 會自動換算成日期，不靠 AI 自己算。
- **直接講筆記名稱**：可以寫「原子習慣」或 `[[原子習慣]]`，Agent 會找到對應的筆記。
- **說出你要的結果**：要回答、要建立筆記，還是要加標籤？要建立筆記的話，說明想放在哪個資料夾。
- **一次一件事**：每個任務最多使用 5 次工具，而且讀取的內容量有上限，太大的任務可能做不完。可以拆成幾個任務，或在同一個對話中接著說「再幫我……」。

## 其他須知

- **速度**：只用 CPU 時，一個任務約 1–4 分鐘；有 GPU 會快很多。讀越多內容越慢。
- **多輪任務**：Agent 會記得之前的任務與最終回答，可以接著下指令。按 **New task** 重新開始。
- **語言**：用中文下指令就用中文回答，英文亦然。
- **連結可信度**：最終回答只會保留真正存在的筆記連結，AI 編造的連結會變成純文字。
- 任務紀錄只存在記憶體中，關閉 App 或換 vault 時清空；等待中的修改視為拒絕。
- 換成不支援工具的模型時，會顯示「does not support tool calling」，請到 [AI 設定](ai-setup.md#ai-設定) 換模型。
