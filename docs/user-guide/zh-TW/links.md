# 連結與反向連結

連結是 Knowmon 的核心。與其把筆記塞進層層資料夾，不如讓每個想法連到相關的想法，之後無論從哪一篇出發，都能沿著連結找到其他相關的內容。

## 寫一個連結

用兩組方括號包住筆記名稱：

```markdown
這個概念和 [[深度工作]] 裡講的「刻意練習」很像。
```

### 自動補全

輸入 `[[` 後會跳出筆記清單（同時顯示所在的資料夾）：

- 繼續打字縮小範圍，`↑` `↓` 選擇，`Enter` 插入，`Esc` 關閉。
- 選單關掉後想再叫出來，按 `Ctrl+Space`。
- 插入的會是**能唯一指到那篇筆記的最短寫法**：大部分時候只有檔名，例如 `[[原子習慣]]`；若有兩篇同名，則會帶上資料夾，例如 `[[讀書筆記/原子習慣]]`。

### 其他寫法

| 寫法                    | 意思                                               |
| ----------------------- | -------------------------------------------------- |
| `[[原子習慣]]`          | 連到名為「原子習慣」的筆記                         |
| `[[讀書筆記/原子習慣]]` | 指定資料夾，用於有同名筆記時                       |
| `[[原子習慣\|這本書]]`  | 連到「原子習慣」，但顯示為「這本書」               |
| `[[原子習慣#第三章]]`   | 連到「原子習慣」（目前會開啟筆記，不會捲到該標題） |

### 開啟連結

| 操作              | 作用           |
| ----------------- | -------------- |
| `Ctrl+點擊`       | 在目前分頁開啟 |
| `Ctrl+Shift+點擊` | 在新分頁開啟   |

不需要按 `Ctrl` 的單純點擊只會移動游標，方便你編輯連結文字。

## 先寫連結，之後再建立筆記

你可以連到**還不存在**的筆記。這在寫作時很好用：想到一個值得展開的概念，先寫成 `[[連結]]`，之後再補。

`Ctrl+點擊`一個尚未建立的連結時，Knowmon 會在 **vault 根目錄**建立同名筆記並開啟它。之前所有指向這個名稱的連結都會自動接上，不需要重新整理。

**範例**：在「深度工作」裡寫下

```markdown
這讓我想到 [[注意力殘留]] 的問題。
```

`Ctrl+點擊`它，就會得到一篇新的「注意力殘留.md」，它的 Backlinks 面板已經列出「深度工作」。

## 連結如何對應到筆記

Knowmon 用以下規則決定 `[[某個名稱]]` 指向哪一篇：

1. **不分大小寫**：`[[english note]]` 會連到 `English note.md`。
2. 寫了 `/` 時比對**路徑結尾**，否則只比對**檔名**。
3. 有多篇符合時，選**路徑最短**的那篇；一樣短則依字母順序。
4. `.md` 副檔名可寫可不寫。

## 改名時要注意

改名**不會**自動改寫其他筆記裡的連結。把「原子習慣」改名為「Atomic Habits」後，其他筆記裡的 `[[原子習慣]]` 會變成指向不存在的筆記。需要的話，請用搜尋找到這些連結並手動修改。

## 反向連結（Backlinks）

右側面板的 **Backlinks** 分頁列出所有連到目前筆記的筆記，並顯示**連結所在的那一行**，讓你不用打開就知道對方在什麼脈絡下提到這篇。

- 點擊在目前分頁開啟該筆記，`Ctrl+點擊`或中鍵開在新分頁。
- 沒有任何筆記連過來時顯示「No notes link here yet.」。

**範例**：在 test-vault 中開啟「深度工作」，Backlinks 會列出：

- 2026-10-04 —「讀了 [[深度工作]] 的第二章，想到可以把專注時段記錄下來。」
- 歡迎 —「讀書筆記：[[原子習慣]]、[[深度工作]]」
- 原子習慣 —「和 [[深度工作]] 一起讀效果更好。」

## 除了手寫連結

Knowmon 還會自動產生其他種類的關聯，它們顯示在圖譜中，但不會出現在 Backlinks 面板：

- **時間邊**：同一段時間寫的、講同一天的事、同一資料夾裡的前後篇。見 [時間脈絡](time.md)。
- **Semantic 邊**：內容相似的筆記（需要本地 AI）。見 [圖譜](graph.md)。
